# StellarNet Telecom Native Apps

Native iOS and Android shells use the production StellarNet Telecom control plane:
https://oeql-quantum-telecom-phone.onrender.com/

GitHub Actions builds an Android APK and an unsigned iOS .app. Store-signed distribution requires the owner's Apple/Google signing credentials and store accounts; none are fabricated or committed.

“Quantum” is experimental software/control-plane branding, not a claim of deployed quantum radio.
